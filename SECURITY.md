# Security Policy

If you find a vulnerability, please report it privately through GitHub's
[private vulnerability reporting](https://github.com/lumenworksco/Nihongo/security/advisories/new)
instead of opening a public issue. You can expect an initial response within a week.

Supabase anon keys and VAPID public keys are public by design; row-level security policies in `supabase/schema.sql` protect user data.
